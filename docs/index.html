Experiment setup

Both samplers use the same map seeds and budget in each paired trial. Hybrid replaces every other input shape and wall density with a case from fixed edge sequences.

The fault scenarios are deliberate fixtures for one reference generator. Detection rates describe this benchmark. Games with other generators or terrain rules need their own validation checks.
